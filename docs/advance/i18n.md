# I18N Internationalization

Enable `AutoGenerateI18N` in `Tools.Config.props` and place `.resw` files under `Strings`, for example:

```text
Strings/
  en-us/
    Resources.resw
  zh-cn/
    Resources.resw
```

Define keys such as `Download` as ordinary WinUI resources. Keys become C# enum members and properties directly, so use valid C# identifiers. If there are no `.resw` files, generation is skipped with diagnostic `SPLW001`.

## Generated API

Building generates `ResourceKey`, `ResourcesHelper`, `I18N`, and `LocaleExtension` under **`{assembly name}.I18n`**. The generator uses `Compilation.AssemblyName`, which may differ from a custom `RootNamespace`.

```csharp
using ShadowExample.Plugin.Emoji.I18n;

string first = ResourcesHelper.GetString(ResourceKey.Download);
string second = ResourcesHelper.GetString("Download");
string third = I18N.Download;
```

```xml
<UserControl
    x:Class="ShadowExample.Plugin.Emoji.Controls.UserControl1"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    xmlns:i18n="using:ShadowExample.Plugin.Emoji.I18n">
    <TextBlock Text="{i18n:Locale Key=Download}" />
</UserControl>
```

These examples require a `Download` resource. `I18N.Download` is equivalent to `ResourcesHelper.GetString(ResourceKey.Download)`. `Locale` reads the string when providing its XAML value; it does not create a binding for runtime language changes.

## Resource sources

- External plugins identified by `[MainPlugin]` use `ApplicationExtensionHost.GetResourceMapForAssembly()`.
- SDKs with an `[ExportMeta]` record and `[MainPlugin(BuiltIn = true)]` plugins use the host resource manager with assembly-prefixed keys.
- Ordinary hosts use `ResourceLoader`.

Load external plugin assemblies before reading their resources. Preserve generated PRI and resource files when [packaging](/plugin/pack).
