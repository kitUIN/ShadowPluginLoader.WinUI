# I18N 国际化

在 `Tools.Config.props` 中启用 `AutoGenerateI18N`，将 `.resw` 文件放入 `Strings`，例如：

```text
Strings/
  en-us/
    Resources.resw
  zh-cn/
    Resources.resw
```

按普通 WinUI 资源文件写入 `Download` 等键。键会直接生成 C# 枚举成员和属性，应使用合法的 C# 标识符。没有 `.resw` 时会报告 `SPLW001` 并跳过生成。

## 生成的 API

构建后在 **`{程序集名称}.I18n`** 下生成 `ResourceKey`、`ResourcesHelper`、`I18N` 和 `LocaleExtension`。生成器使用 `Compilation.AssemblyName`，不一定等于自定义的 `RootNamespace`。

```csharp
using ShadowExample.Plugin.Emoji.I18n;

string first = ResourcesHelper.GetString(ResourceKey.Download);
string second = ResourcesHelper.GetString("Download");
string third = I18N.Download;
```

```xml
<UserControl
    x:Class="ShadowExample.Plugin.Emoji.Controls.UserControl1"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    xmlns:i18n="using:ShadowExample.Plugin.Emoji.I18n">
    <TextBlock Text="{i18n:Locale Key=Download}" />
</UserControl>
```

以上要求资源文件中包含 `Download`。`I18N.Download` 等效于 `ResourcesHelper.GetString(ResourceKey.Download)`。`Locale` 在提供 XAML 值时读取字符串，不会自动建立运行时语言变更的绑定。

## 资源来源

- 普通外部插件：识别 `[MainPlugin]`，通过 `ApplicationExtensionHost.GetResourceMapForAssembly()` 读取插件资源。
- SDK（带 `[ExportMeta]` 的 record）或 `[MainPlugin(BuiltIn = true)]`：使用宿主资源管理器，资源键带程序集前缀。
- 普通宿主：使用 `ResourceLoader`。

读取外部插件资源前应已完成程序集加载；打包时保留生成的 PRI 和资源文件。参见[插件打包](/zh/plugin/pack)。
