# 插件开发

完成[SDK 和主程序的准备工作](/zh/init/)后，就可以开始写插件了。先从[创建插件项目](/zh/plugin/create)开始，再根据需要添加功能。

如果插件需要界面，可以写[自定义控件](/zh/plugin/control)，用[资源字典](/zh/plugin/resourcedictionary)管理颜色和样式。图片等文件放进[资源文件夹](/zh/plugin/assets)，通过[插件资源路径](/zh/plugin/msplugin)访问。

想记住用户设置，可以添加[配置文件](/zh/plugin/config)；想支持多种语言，可以使用[国际化帮助类](/zh/advance/i18n)。

写好后，把插件[打包](/zh/plugin/pack)，再回到主程序中[安装试用](/zh/plugin/install)。主程序还可以通过[插件事件](/zh/plugin/event)了解插件的加载和启用情况。
